# Rompiendo Barreras – Ecosistema Web y Móvil

Sistema integral desarrollado para la gestión administrativa y atención de usuarios de un centro de rehabilitación (proyecto académico). El ecosistema se divide en dos módulos principales conectados a una misma arquitectura de datos:

## Estructura del Repositorio

* **`/web-admin` (Plataforma Web):** Panel administrativo y portal de gestión desarrollado en **PHP**, **HTML5/CSS3** y **SQL**, con control de sesiones, gestión de registros de clientes y actualización de base de datos.
* **`/app-movil` (Aplicación Móvil):** Aplicación multiplataforma orientada a los usuarios finales, desarrollada con **Flutter (Dart)**.

## Tecnologías Utilizadas

* **Web y Backend:** PHP, HTML5, CSS3, SQL
* **Desarrollo Móvil:** Flutter, Dart
* **Control de Versiones:** Git y GitHub

## Funcionalidades Principales

* Registro e inicio de sesión para administradores y usuarios.
* Gestión administrativa de registros y seguimiento desde el entorno web.
* Interfaz móvil para consulta y acceso de usuarios finales.
